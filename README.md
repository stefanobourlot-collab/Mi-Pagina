# 🐱 GitHub Cat Runner - Mi Página Personal

## 🌟 Descripción

Una página web completa con **clima **, **cotización del dólar blue**, **galería de fotos personal** y un **juego arcade** estilo Chrome Dino pero con el **Octocat de GitHub** esquivando código malicioso.

## 🚀 Características

### 🌤️ Clima automático
- API de Open-Meteo para datos meteorológicos
- Temperatura, humedad, velocidad del viento
- Se adapta automáticamente a tu ciudad

### 💵 Finanzas en tiempo real
- Cotización del **Dólar Blue Argentina** vía API
- Índices internacionales (S&P 500, Nasdaq, Dow Jones)
- Actualización automática cada 30 segundos

### 📸 Galería de fotos
- Sección "Fotos de Viaje" con imágenes personalizadas
- Sección "Mi Gata Milu" con fotos de mascota
- Diseño responsive con grid dinámico

### 🎮 Juegos
- **Adivina el Número** (juego simple de adivinanza)
- **GitHub Cat Runner** (juego arcade completo)
  - Octocat personalizado dibujado con Canvas
  - Obstáculos: código malicioso, bugs, virus
  - Sistema de puntuación y récord local
  - Velocidad progresiva
  - Compatible con **tacto** (móvil) y **teclado** (PC)

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| HTML5 | Estructura de las páginas |
| CSS3 | Estilos, diseño responsive, animaciones |
| JavaScript (Vanilla) | Toda la lógica del juego y APIs |
| Canvas API | Dibujo del juego y animaciones |
| Open-Meteo API | Datos climáticos en tiempo real |
| DolarAPI.com | Cotización del dólar blue |
| Geolocation API | Detección de ubicación del usuario |
| LocalStorage | Guardado de récords locales |
| GitHub Pages | Hosting gratuito |

## 🎯 APIs utilizadas

- **Open-Meteo** - Clima gratuito sin API key
- **DolarAPI** - Cotizaciones del dólar Argentina
- **Geolocation API** - Ubicación del usuario
- **LocalStorage API** - Persistencia de datos local
